## 六个维度：实际用了什么，而非臆造六个官方工具

| 维度 | 内置 Computer Use 的实际记录 | 当前 RCU 及明确缺口 |
|---|---|---|
| 入口、对象与状态 | 直接 `mcp__cua_repl.js`；`getApp/listApps`、浏览器/tab 对象；JS 对象保留在 REPL | 当前技能必须用 Host 加载的 `computer.*`；终端客户端测试不能替代这个入口。设备连接、窗口绑定和业务任务仍需独立 |
| 观察与输出 | `getAXState`/`getScreenshot`/联合观察，状态差异和截图用于后续决策 | 已有 snapshot、frame refs 和预览；观察/复查较重，分页后部分 role 缺失，preview/诊断重复较多；需精简而不是隐去错误 |
| 预先确定的动作 | `click/drag/pressKey/setValue/performSecondaryAction`；一个 JS cell 可顺序 await 多个已确定动作后观察 | `withInput` 保持有界 lease，但模型侧当前常需每个动作前再观察；应减少重复全树/全图检查，不能取消必要的原生身份、焦点和元素校验 |
| 连续绘制 | Paintbrush 一条两点 drag；JS Paint 用起始 drag + 多个点击完成 11 个多边形 | RCU 已有单次请求、设备节拍的有界多路点轨迹；本次原生 UIA 途中失效，不能声称已经和 CUA 一样稳定；CUA 本组也没有任意路径/视频实测 |
| 可视反馈 | Paintbrush 笔画截图可见箭头和光晕；JS Paint 静态成图不能证明全程光标跟随 | 要独立交付设备侧可见反馈、截图中反馈和反馈时间线；不抢焦点、不截获输入，且不可让覆盖层破坏命中检测 |
| 结果、失败与恢复 | 图形、网页存储重开、文件下载分开记录；采集失败后动作结果可能不明 | 保留 RCU durable request、operation ref、终态/抬键/资源释放与不重放；保存、重开和效果验证不能被 dispatch ACK 或一张截图替代 |

观察到 CUA 的“顺序批量动作 + 必要节点观察”值得借鉴，但没有证据支持“零延迟”
或“模型持续读取桌面视频”。本组没有抓取真实私有 socket 协议；不从错误栈里的
Socket 名称、持久 REPL 或静态图像推断它使用哪种流式传输。

## 入口与证据偏差：不能抹掉

- RCU 那轮通过真正 MCP 执行，但调用者是终端测试程序。它仅证明相应运行链路，
  不证明用户要求的 Host 原生 MCP/plugin/skill 入口；已停止该客户端路径。
- Mac 新任务的**实际绘图**通过 CUA GUI 完成，没有脚本绘制或导入参考图。
  但导出排查混入 pageAssets、Playwright download 等待、只读 DOM 尺寸检查及
  失败的 `toDataURL`；这些不计为纯 GUI 保存/重开通过。最终查看的是未经编辑
  的完整原生截图，而不是脚本导出的成品。
- 任务还尝试过被拒绝的 Codex 本体 UI 访问。此尝试不合既有边界，不以其失败
  请求或后续截图作为绕行许可。已明确禁止继续使用该路径。
- 因此本轮不能冠以“全部原生 GUI 验收通过”；同时不能否认已实际画出的图形。

## 下一步实现顺序及过关条件

1. **原生 Host 入口约束先落实。** 已把“终端真实 MCP 客户端不等于 Host 原生
   入口”和独立保存节点写入 canonical skill。后续 RCU GUI 验收只计入 Host
   当前加载的 RCU 工具调用；发现 adapter/catalog 不匹配时修入口，不绕行。
   不在 server 中按某个业务任务或客户端名字硬编码许可。
2. **Pointer 作为独立能力实现。** 设备侧可见、不会抢焦点/拦截输入，和截图/原生
   坐标一致；取消、失效、断线时正确清理。分别验收实屏跟随、截图呈现及时间线。
   本轮没有实现此能力，也不把 skill 更新算作实现。
3. **连贯输入保持 native 节拍。** 在真实应用验证有界路径、控制通道可用、Stop
   后抬键和效果不明时不重放。对 ElementFromPoint 的短暂失效研究受限只读重查，
   重新证明作用域/敏感元素/焦点；不能跳过检查或重放已经插入的事件。
4. **减少无关观察与输出。** 补齐分页语义信息；常规结果只给相关控件、变化和
   必要执行凭据，完整诊断按引用读取。针对相同元素连续编辑研究只读精确复查，
   避免每个已确定动作都做重复全树/全图工作；变更状态仍立即停止旧计划。
5. **重做公平闭环。** 明确同一画稿、工具/应用版本、人工介入和结束节点。Host
   原生工具 → 绘图 → 保存 → 重新打开必须各有证据。GUI/SSH 可互补，但终端
   的准备/校验不能冒充 GUI 节点。Mac production RCU agent 仍未完成。

以上是基于实际记录的实现方向，不是已经完成的交付。通用传输复用及 Windows
桌面发现修复已有独立提交；视觉反馈与整轮交互效率尚不能据此宣布合格。
